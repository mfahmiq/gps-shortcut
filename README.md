# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty
[u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9):
write the GPS's one line excuse for sending the driver down the wrong road.

## The entry

> We're not lost, we're early to a wedding we weren't invited to. The map already RSVP'd plus one.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the entry text above to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). No network, no file reads, no secrets — the text is
embedded verbatim in `main.py`.
